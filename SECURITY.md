# Security Policy

## Reporting a vulnerability

Please report security issues privately to **hola@tucunar.com**. Do not open a
public GitHub issue for a vulnerability.

Include enough detail to reproduce the issue: affected version, Android version,
steps, and any relevant logs with personal data removed. We will acknowledge the
report and coordinate disclosure.

## Scope

This repository contains the Android client and Firestore security rules. The
Firebase project used by the official build is operated by Tucunar SpA; the
security of a self-hosted Firebase project is the responsibility of its owner.

## Supported versions

Security fixes are applied to the latest release. Older releases may not receive
backports.
